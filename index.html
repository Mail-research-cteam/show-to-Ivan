Proto

Публикация, обновление и защищённый просмотр HTML-прототипов.

О сервисе

Загрузите HTML-файл в папку команды и поделитесь ссылкой. Коллеги смогут открыть прототип на компьютере или телефоне. Для входа нужен одноразовый код на почту @vkteam.ru, для просмотра прототипа — четырёхзначный ПИН.

При обновлении файла ссылка сохраняется. Proto хранит четыре последние версии для отката. Файлы можно распределять по папкам и подпапкам.

Для загрузки через ИИ скопируйте одноразовый промпт из папки в своего агента. Для обновления возьмите промпт из карточки прототипа — он действует 10 часов.
